ONE HOME / ONE MATHS / ONE READER — 5 October 2026

THREE SITES, ONE SCHOOL DATABASE
1. Back up your existing repository files and database before installing.
2. Run the separately supplied PRIVATE OneHome-Trio-Database.sql in the SAME multi-school Supabase project as OneLearn. This contains the schema upgrade, the existing topic bank and the new full novels. Run it once for all three websites. It is repeatable and keeps existing progress, schools and roles. Do not upload this SQL to GitHub: it includes teacher answer keys. A PostgreSQL client can run the file if your dashboard editor rejects a large paste.
3. Upload the contents of OneHome.zip to your OneHome repository; OneMaths.zip to OneMaths; OneReader.zip to OneReader. Every ZIP has files directly at its root. Keep the old homework files included in OneHome so previous work/results remain accessible.
4. In EACH config.js set the three app addresses to your real HTTPS URLs, ending in /. The supplied Supabase URL and publishable key are preserved. Never insert a service-role key or OAuth client secret in these files.
5. Open OneHome/index.html?school=YOUR-SCHOOL-SLUG and sign in using your existing staff email/password. The existing OneLearn school and staff provisioning remains unchanged. Configure the exam board, enabled years and availability. Import classes or refresh ONE EDUCATE. In People & classes, download the email roster template, fill email and provider (azure / google / email) and upload it. Staff assignments and school-scoped server permissions remain enforced.
